# PHP Security Skill

- Hash passwords using `password_hash()` and verify with `password_verify()`.
- Use PDO prepared statements exclusively to prevent SQL injection.
- Validate and sanitize all user inputs.
- Implement robust CSRF protection for state-changing requests.
- Enforce secure session configurations (`HttpOnly`, `Secure`, `SameSite`).
- Ensure proper authorization checks on every protected endpoint.
